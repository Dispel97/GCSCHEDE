🌐 Frontend Online (build statica) Consigliato

Contiene tutti i file HTML + JS + CSS della versione online completa (con Magazzino, Notifiche, Storico seriale, tag liberi). Uploadalo su qualsiasi hosting statico gratuito (Cloudflare Pages, Netlify, GitHub Pages).

⚠️ Richiede il backend FastAPI attivo (vedi guida migrazione). Prima di uploadare, modifica la env var REACT_APP_BACKEND_URL nel tuo hosting.

⬇️ Scarica .zip (2 MB)

📱 App Offline Android (HTML singolo)

File HTML autonomo di 2.5 MB con tutte le librerie inlinate. Funziona senza server anche offline: parse PDF, generazione nota, scanner barcode/QR, foto, invio Gmail.

Puoi uploadarlo su qualsiasi hosting statico oppure aprirlo direttamente da telefono.
Non include Magazzino, Notifiche, multi-utente.

⬇️ Scarica HTML offline (2.6 MB) 👀 Prova al volo
